# 스타트업 투자유치 뉴스 자동 브리핑

매일 아침, 최근 24시간 동안 나온 스타트업 투자유치 기사를 모아 **기업명 · 업종 · 투자 단계 · 금액 · 투자사**를 표로 정리해 텔레그램(과 선택적으로 노션)으로 보내주는 도구입니다.

## 동작 방식

```
구글 뉴스 RSS (투자 유치, 시드, 프리A, 시리즈A/B 검색어)
  → 중복 기사 제거, 최근 24시간만 (월요일은 72시간)
  → Gemini가 제목에서 기업명·업종·단계·금액·투자사 추출 (JSON)
  → 결과를 기사 제목과 다시 대조해 검증 (⚠️확인필요 표시)
  → 텔레그램 브리핑 + data/deals.csv + data/briefings/날짜.md
  → (선택) 노션 데이터베이스에 한 건씩 저장
  → GitHub Actions가 평일 08:43(한국시간)에 자동 실행
```

## AI 결과를 그대로 믿지 않도록 한 장치

- 프롬프트에서 **기사에 없는 내용은 추측하지 말고 비워두도록** 지시했습니다. 금액이 없으면 '비공개'로 표시됩니다.
- AI가 뽑은 기업명이 **원문 제목에 실제로 없으면** `⚠️확인필요`를 붙입니다. 같은 기사에서 결과가 여러 개 나오면 검증을 통과한 것만 남깁니다.
- 달러 금액은 1달러=1,400원으로 환산하고 `(환산)`이라고 표시합니다.
- 모든 건에 원문 링크가 붙어 있어 직접 확인할 수 있습니다.

## 쌓이는 데이터

`data/deals.csv`에 매일 결과가 쌓입니다. 한 달쯤 모이면 업종별·단계별 투자 건수, 자주 등장하는 투자사 등을 엑셀 피벗테이블로 분석할 수 있습니다.

## 설치 가이드 (약 30분)

### 1단계. Gemini API 키 (무료)
1. https://aistudio.google.com 접속 → 구글 계정 로그인
2. 왼쪽 **Get API key → Create API key**
3. 키를 복사해 둡니다. 무료 사용량으로 하루 1번 실행은 충분합니다.

### 2단계. 텔레그램 봇
DART 알림에서 만든 봇의 **토큰과 Chat ID를 그대로 재사용**하면 됩니다. (따로 받고 싶으면 @BotFather에서 하나 더 만드세요)

### 3단계. GitHub에 올리기
DART 알림과 같은 방법으로 새 저장소 `startup-funding-briefing`(Public)을 만들고 파일 전체를 업로드합니다. `.github` 숨김 폴더도 꼭 같이 올려야 합니다.

### 4단계. 비밀 키 등록
**Settings → Secrets and variables → Actions → New repository secret**

| Name | Secret | 필수 |
|---|---|---|
| `GEMINI_API_KEY` | 1단계 키 | ✅ |
| `TELEGRAM_TOKEN` | dart-bot과 같은 봇 토큰 | ✅ |
| `CHAT_ID` | dart-bot과 같은 Chat ID | ✅ |
| `NOTION_TOKEN` | 아래 노션 설정 참고 | 선택 |
| `NOTION_DATABASE_ID` | 아래 노션 설정 참고 | 선택 |

### 5단계. 첫 실행
**Actions → 스타트업 투자유치 브리핑 → Run workflow** (hours에 `72`를 넣으면 3일치를 봅니다)

## (선택) 노션 데이터베이스 연결

1. https://www.notion.so/my-integrations → **새 API 통합** → 이름 입력 → 저장 → **내부 통합 시크릿** 복사 → `NOTION_TOKEN`
2. 노션에서 새 페이지 → **/데이터베이스 - 전체 페이지** 생성
3. 속성을 **정확히 이 이름과 유형**으로 만듭니다.

| 속성 이름 | 유형 |
|---|---|
| 기업명 | 제목 (기본 '이름' 속성의 이름을 바꾸기) |
| 업종 | 텍스트 |
| 단계 | 선택 |
| 금액(억원) | 숫자 |
| 투자사 | 텍스트 |
| 요약 | 텍스트 |
| 검증 | 선택 |
| 날짜 | 날짜 |
| 링크 | URL |

4. 데이터베이스 페이지 오른쪽 위 **··· → 연결 → 1번에서 만든 통합** 추가
5. 데이터베이스 주소 `notion.so/xxxx/`**`32자리문자`**`?v=...` 에서 32자리가 `NOTION_DATABASE_ID`

## 문제가 생기면

- `404` / `model not found` 오류: Gemini 모델 이름이 바뀐 경우입니다. Secrets에 `GEMINI_MODEL`을 추가하고 AI Studio에 나오는 최신 Flash 모델 이름(예: `gemini-2.5-flash`)을 넣은 뒤, `daily.yml`의 env에 `GEMINI_MODEL: ${{ secrets.GEMINI_MODEL }}` 한 줄을 추가하세요.
- `429` 오류: 무료 사용량 초과입니다. 잠시 후 다시 실행하세요.
